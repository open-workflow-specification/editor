# Welcome to the OWS Editor

The **Open Workflow Specification Editor** brings text and diagram editing together in one embeddable React component. Edit a workflow as JSON or YAML and see the diagram update alongside it; diagram edits are synchronized back to the text editor.

## Get started

Install `@openworkflowspec/dual-editor` and its workspace dependencies, then provide workflow content and a language service worker. The component fills its parent, so give the parent a definite height.

```tsx
import { useState } from "react";
import { DualEditor } from "@openworkflowspec/dual-editor";
import LanguageServiceWorker from "@openworkflowspec/text-editor/worker?worker";
import "@openworkflowspec/dual-editor/styles.css";

const initialWorkflow = `{
  "document": {
    "dsl": "1.0.0",
    "namespace": "examples",
    "name": "hello-world",
    "version": "1.0.0"
  },
  "do": [{ "log": { "message": "Hello, World!" } }]
}`;

function WorkflowEditor() {
  const [content, setContent] = useState(initialWorkflow);

  return (
    <div style={{ height: "600px" }}>
      <DualEditor
        content={content}
        createLanguageServiceWorker={() => new LanguageServiceWorker()}
        onContentChange={setContent}
      />
    </div>
  );
}
```

## Props

### Workflow

  <PropCard

    required
    description="Workflow definition as JSON or YAML."
  />
  <PropCard
    name="createLanguageServiceWorker"
    type="() => Worker"
    required
    description="Creates the language service worker used by the Text Editor."
  />
</div>

### Editor options

<div className="dual-editor-prop-grid">
  <PropCard
    name="language"
    type="TextEditorLanguage"
    defaultValue="json"
    description="Text Editor requires a language. Dual Editor defaults to JSON."
  />
  <PropCard
    name="isReadOnly"
    type="boolean"
    defaultValue="false"
    description="Makes both editors read only."
  />
  <PropCard
    name="locale"
    type="string"
    defaultValue="en"
    description="Diagram Editor requires a locale. Dual Editor defaults to English."
  />
  <PropCard
    name="colorMode"
    type="ColorMode"
    defaultValue="system"
    description="Color mode passed to both editors."
  />
</div>
